# Dokumen referensi

Folder ini berisi proposal, quotation, dan referensi desain yang tidak digunakan oleh runtime website.

- `company-profile-proposal.pdf`: proposal company profile.
- `website-proposal-editable.pptx`: versi proposal yang dapat diedit.
- `website-quotation.pdf`: quotation website.
- `design-reference.pdf`: referensi visual awal.

File di folder ini aman dihapus dari salinan deployment production, tetapi dipertahankan di repository kerja sebagai arsip bisnis.
